# Triage labels

The labels and what they mean in this repo are in [CONTRIBUTING.md](../../CONTRIBUTING.md#labels). The mattpocock/skills roles map one to one:

| Role in mattpocock/skills | Label in this repo |
| ------------------------- | ------------------ |
| `needs-triage`            | `needs-triage`     |
| `needs-info`              | `needs-info`       |
| `ready-for-agent`         | `ready-for-agent`  |
| `ready-for-human`         | `ready-for-human`  |
| `wontfix`                 | `wontfix`          |

Category labels are `bug` and `enhancement`.
